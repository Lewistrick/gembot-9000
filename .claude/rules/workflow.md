# Branches and pull requests
- After adding new functionality on a new branch, always open a pull request for it (don't wait to be asked).
- Before adding work to an existing branch, check whether its pull request is still open. If it was already merged, start a new branch from the latest `main` instead of adding commits to the merged one.
- Merging to `main` redeploys the app, so say so in the pull request description.
