# Backend
- Never guess what the user meant. If there is uncertainty: ask the user what to do, propose several solutions and recommend one, and leave room for the user to add extra comments. This goes for all parts of the app: game logic, navigation flow, contradicting rules, and visual elements.
- Don't do byte compilation. We already have ty and ruff in place to check code quality and style.
